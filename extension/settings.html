Environments & deep-link rule sets

Environments

Each environment is a Dynatrace tenant URL plus a read-only platform token (storage:*:read scopes). The active one is what the side panel connects to. Tokens are stored in chrome.storage.local on this device only — dtui is read-only, so no write scopes are needed.
Reload / reopen the side panel after switching the active environment.

Deep-link rule sets

A rule set is a named bundle of rules that recognize ids on a web page and inject a dtui button to jump to a filtered view. Toggle a set to enable/disable all its rules at once — only enabled sets take effect. This extension ships with none; a customer app hosts its own bundle in its repo (see extension/examples/). An action may set a target environment (a tenant URL); dtui auto-switches to whichever environment above points at that host — so a shared bundle needs no agreement on local names. Reload the target page after changes.
